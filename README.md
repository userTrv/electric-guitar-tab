# Гитарная партия

Шестилинейная табулатура одной электрогитарной партии с ролика около 26 секунд.

- Строй: E–A–D–G–B–E
- Темп: ♩ = 173, размер 4/4
- Высоты сняты по гармоническому спектру и сверены с ладом на кадре (бокс 7–11)

Готовый лист: [guitar-tab.pdf](guitar-tab.pdf). На третьей странице — таблица, чем подтверждена каждая нота.

Исходный ролик, аудио и кадры с человеком в репозиторий не входят.

Отдельного ГОСТа на рисунок табулатуры нет. Лист сделан как обычная шестилинейная табулатура: тонкая струна сверху, строй слева, лад на линии, ритм над станом. Подпись листа — по составу ГОСТ Р 7.0.4-2020. В библиотечном учёте такая форма — табулатура, код h в ГОСТ Р 7.0.100-2018.
